# DESIGN.md — TRAE 高效开发实战（1024 济宁）

> 通用设计原则分支（技术分享场景，不命中学术/咨询/红金三类预设风格）。
> 视觉母题：**终端窗口**——近黑背景、单一信号绿、等宽字体做数字与代码，网格线做装饰。

## 1. 画布与母版

画布 1280 × 720。内容页三区固定：

| 母版区 | 垂直位置 | 高度 | 内容 |
|---|---|---|---|
| A 标题块 | y = 40 → 126 | 86 | 主标题 34px bold + 引导句 17px（间距 10） |
| B 内容区 | y = 144 → 630 | 486 | 正文 / 图表 / 配图 / 卡片 |
| C 页脚条 | y = 644 → 672 | 28 | 左：`TRAE 高效开发实战 · 1024 济宁` 12px；右：`NN / 11` 12px |
| 页面 padding | 上 40 / 下 48 / 左右 72 | — | 内容可用宽 1136 |

封面 / 结束页采用自定义版式，省略 A/C 分区（保留右下角页码或落款）。

## 2. 颜色系统（4 hex，全篇唯一色板）

| 角色 | hex | 用途 | 面积 |
|---|---|---|---|
| 主色 · 墨底 | `#0A0D0C` | 页面背景、全幅底 | 65–80% |
| 辅色 · 卡面 | `#1A2620` | 卡片、代码块底、表格斑马 | ≤ 20% |
| 强调色 · 信号绿 | `#3DDC84` | 巨型数字、序号、关键标注、进度条、边框高亮 | ≤ 10%（Hero ≤ 18%） |
| 文本色 · 骨白 | `#E9F1EC` | 标题与正文 | 剩余 |

派生只用透明度，不引入新 hex：
- 次要文本：`#E9F1EC` + opacity 0.55
- 三级文本 / 页脚：`#E9F1EC` + opacity 0.38
- 卡片描边：`rgba(61,220,132,0.16)`；网格线：`rgba(233,241,236,0.06)`
- 强调色半透明填充：`rgba(61,220,132,0.10)`

渐变方案：仅两处使用 `linear-gradient(135deg, rgba(61,220,132,0.16) 0%, rgba(10,13,12,0) 70%)`——封面右上角光晕、第 7 页数字背后。禁止大面积渐变。

页面色彩映射：
- 常规页：墨底 72% + 卡面 18% + 信号绿 ≤ 6%
- 07 / 11（Hero）：信号绿提到 14–18%，其余页压到 5% 以下

## 3. 字体系统

| 层级 | 字号 / 字重 / 行高 | 字体 | 用途 |
|---|---|---|---|
| 封面主标题 | 54 / bold / 1.16 | 微软雅黑 | 仅封面 |
| 结束页大字 | 44 / bold / 1.3 | 微软雅黑 | 仅结束页 |
| 巨型数字 | 104 / bold / 1.0 | Consolas | 第 7 页锚点 |
| 页面主标题 | 34 / bold / 1.25 | 微软雅黑 | A 区 |
| 引导句 | 17 / normal / 1.5 | 微软雅黑 | A 区副行，opacity 0.55 |
| 卡片标题 | 21 / bold / 1.3 | 微软雅黑 | 卡片头 |
| 正文 | 16 / normal / 1.65 | 微软雅黑 | 段落 |
| 时间码 / 序号 | 28–40 / bold | Consolas | 编号、时间、数据 |
| 页脚 | 12 / normal | 微软雅黑 | C 区 |

- 中文家族：微软雅黑（唯一）；等宽家族：Consolas（唯一）。
- 巨型数字与序号一律 Consolas，与正文形成字体对比。

## 4. 信息密度与容器

- 常规内容页留白 ≤ 30%；Hero 页允许 35–45%，但留白围绕核心元素。
- 卡片填充率 ≥ 85%：高 ≥ 300px 的卡片正文 ≥ 100 字。
- 卡片尾部元素（标注 / 引文条）用 `marginTop: 'auto'` 钉底；同行兄弟卡三段等高。
- 每页至少 1 个视觉锚点：巨型数字 / ≥ 40% B 区面积的图 / ≥ 40px 的大字。

## 7. 装饰白名单

只允许：1px 细网格线（`rgba(233,241,236,0.06)`，72px 栅格）、信号绿短竖线（4×N，做标题左标）、序号数字、`rgba(61,220,132,0.10)` 的半透明底块。
禁止：圆角过大（统一 4–8px）、阴影光晕（除封面与 07）、图标堆砌、Emoji、渐变彩虹色。
